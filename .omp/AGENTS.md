# MarketingOrPMP_VibeCoding — 项目约定

## 项目目的

消费电子企业三大业务域（GTM 营销、IPD 研发项目管理、招聘人才管理）的 Agent 系统方案库与实现。方案库见 `docs/analysis/2026-09-16-vibecoding-catalog-and-acceleration.md`。


## 业务背景

- 飞智科技：消费电子品牌，"产品体验领先"核心战略（手游外设方向为推断，待确认）
- 三大业务域：市场营销（GTM）、研发项目管理（IPD）、招聘与人才管理
- 合作模式：AI/IT 职能由 CEO 直管，推动业务自助化 AI 能力建设
- 隐含要求：能从 0 搭建技术体系 + 输出工程化手册让业务自助开发

## 关键阶段自动记录

执行全局约定"关键阶段自动记录"一节（节点、台账、回执三条以全局为准）。本项目实例化：台账在 `docs/RECORDS.md`，分析稿范例 `docs/analysis/2026-09-16-vibecoding-catalog-and-acceleration.md`。



## 工程约定（随实现启动补充）

- 代码位置：待定（monorepo 或按系统分仓）
- 母模板：首个系统做成可 fork 的模板（数据接入→LLM 批处理→人工审核→看板/推送 四段式）
- 三条业务红线：外发内容人工点头发送；招聘不自动拒人；抓取优先用导出数据、注意平台 ToS
