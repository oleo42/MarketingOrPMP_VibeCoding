## 五、方法与数据说明

- **数据源**：online_shopping_10_cats 消费电子子集(平板/手机/计算机)
- **样本**：消费电子评价 11959 条（好评 6134 / 差评 5825），已清洗 BOM/过短/去重
- **情感分类**：LLM 逐条判定（pos/neg/neu）
- **卖点匹配**：方面级关键词规则（10 卖点维度词表，词频校准）。一条评价可命中多个卖点（多标签，声量真实）
- **方法修正链**：HDBSCAN 聚类（738/800 并一坨）→ KMeans 硬划分（簇混合/声量失真）→ 多标签嵌入匹配（相似度挤窄带无法区分）→ **关键词规则匹配**（可解释/零成本/声量准确，采用）
- **净共鸣度**：该卖点所有提及中好评占比。共鸣必须分正负——只看声量只是词频统计，不是共鸣
- **局限**：数据含年代偏差（手机品类多为功能机时代评价，差评偏多）；当前单一品类混数据，无品牌维度（竞品对比待多品牌数据）
